Tensor structure and skeletal fusion data

TensorCategories.jl exposes tensor-categorical structure through generic operations. A category may implement only part of this structure. The manual explains the required hypotheses before using dimensions, traces, modular data, or coherence tests.

The structure setters describe a skeletal presentation; a collection of arrays becomes valid fusion-category data only when the relevant axioms and nondegeneracy conditions hold. See the linked chapters before constructing or interpreting $F$- and $R$-symbols.
